# Printer Toolkit

Micah's Printer Toolkit is a simple Windows batch script designed to make printer management and troubleshooting easier. Instead of manually navigating through different Windows settings and tools, you can access common printer-related functions through one menu.

It lets you view installed printers, check their status, restart the Print Spooler, clear pending print jobs, print test pages, and open printer properties. It also includes shortcuts to Windows printer settings, scanner settings, Devices and Printers, and Print Management.

The goal is to make everyday printer maintenance faster and more convenient, especially when troubleshooting common printing issues. Some features require administrator privileges to work properly.
